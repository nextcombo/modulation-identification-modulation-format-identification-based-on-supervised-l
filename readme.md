# [Modulation Identification] Modulation Format Identification Based on Supervised Learning and High-Dimensional Features [with MATLAB Code]

Introduction to Automatic Modulation Classification (AMC): The basic concept of AMC is identifying unknown modulation types from recognized radio signals, which lays the foundation for subsequent signal preprocessing [1]. AMC represents a significant part in many modern communication systems, such as radio cognitive systems and wireless spectrum sensing [2]. Blind modulation recognition of received signals is also an important challenge in commercial radio systems [3]. Blind modulation methods represent a difficult task without information about the transmitted signal and receiver parameters (such as carrier frequency and channel fading effects). These classification techniques can be used in intelligent receiver applications to improve transmission performance by selecting appropriate modulation schemes compatible with the channel noise pattern [4]. The basic block diagram of AMC is shown in Figure 1. This configuration includes a preprocessing section and a classification algorithm, followed by demodulation based on the detected modulated signal.
In recent years, multi-level modulation methods such as 64 QAM, 256 QAM, 32 APSK, 64 APSK have been widely used in communication systems due to their high data rate transmission capabilities.
Since the distance between points in the constellation chart is narrow, it is more difficult to classify high M-order MPSK, MQAM, and MAPSK than to classify MQAM MAPSK and MPSK in the mode (M<8). Additionally, larger input datasets are needed to train neural network classification algorithms, which increases computational complexity and reduces classification performance. To address these limitations, we believe that the key is to use principal component analysis (PCA) reconstruction combined with neural network classification algorithms to optimize machine learning matrices. Moreover, this network topology enhancement will provide more stable results than traditional deep learning network structures.
Deep learning is a subfield of machine learning, where large amounts of data are used as training inputs and then processed through multi-layer distributed networks with hidden nodes at each layer. Finally, one layer outputs a classifier for prediction. A literature review indicates that, even with appropriate network model selection, although supervised networks have great potential in classification performance, supervised network models have not been thoroughly researched, limited to the AMC field. Moreover, compared to extensive studies on the performance of neural network classifiers in modulation classification (e.g., [6,7]), there is little work addressing the integration of improved feature matrices with neural network classifiers. Therefore, in our work, we investigated the performance of two neural network architectures and evaluated their capabilities: (1) MLP neural network (MLP) [8] and (2) RBF neural network (RBFN) [9]. The remainder of this paper is organized as follows. Section 2 outlines the background and latest hypotheses of this study. Section 3 introduces the role of PCA's reconstructive components in signal feature extraction and their mapping in the learning matrix; Section 4 introduces the classifier based on reconstruction transformation; Section 5 presents simulation results and discussions. Section 6 reviews and summarizes the findings, and Section 7 concludes the paper.
This work extends and consolidates [33] by proposing an in-depth study, highlighting several points previously unconsidered:
1. Reconstructive components can both accurately interpret extracted features and be formulated as squared input to capture more significant structural features within a two-dimensional matrix.
2. The most effective signals are expected, including a set of HOC and [34] suggested five features. HOC and instantaneous features are enhanced by natural logarithmic features such as [35], spectral features, and two types of transformer features [18,36].
3. The reconstruction of PCA components is used to reduce feature bases and optimize raw features. Additionally, the reconstruction component optimizer can determine the maximum fitting parameters and the optimal feature subset for the classifier.
4. Experiments were conducted in 10 modulation schemes including MPSK, MAPSK, MQAM, etc., and the signals were degraded using different channel conditions. The results show that our proposed classifier achieves consistent classification accuracy compared to its peers.
Article illustration
Conclusion This paper proposes a concept of learning matrices, which is a simple and effective form for signal feature extraction. The method first extracts a set of features and forms a matrix, then reconstructs it. Before the input layer of the neural network model, the components of the PCA method are used as transform filters. Two traditional network models were tested to evaluate the combination of the reconstructed component matrix and the network model. Learning matrices can not only utilize nonlinear functions to transform extracted features into new spaces but also use the reconstructed component of the PCA method to map features into geometrical forms. Through simulation platforms, experiments were conducted on 10 modulation types, studying the classification accuracy and performance when MLP and RBF models are combined with the reconstruction transformation of PCA methods. Four ratios of PCA components were used during the training and testing of the models. Compared with some classical and deep learning-based AMC methods, the effectiveness of the proposed method was demonstrated corresponding to its peers. The neural network-based classifier provides sufficient efficiency to recognize all considered modulation types across different channel models.
